# UK Biobank field selection notes

## Core phenotype fields
These include:
- eid
- sex
- age at recruitment
- ICD10 / ICD9 diagnosis fields
- COVID-related fields
- Olink metadata fields

## Symptom fields
Selected symptom fields were collected from UK Biobank Category 160 and include:
- current symptom status
- duration of symptom

These are used to define current symptom burden and prolonged duration consistent with Long COVID logic.

## Olink fields
Protein fields were selected to align, where possible, with the pediatric Olink inflammation panel for cross-cohort comparison.
